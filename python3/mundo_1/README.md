## 🎓 Conhecimentos Adquiridos

### 1. Tipos Primitivos e Saída de Dados
Aprendi a trabalhar com os quatro tipos básicos e como interagir com o usuário:
- `int`: Números inteiros.
- `float`: Números reais/flutuantes.
- `bool`: Valores lógicos (True/False).
- `str`: Cadeias de caracteres (textos).
- **Função `input()`** para entrada e `f-strings` ou `.format()` para saídas formatadas.

### 2. Operadores Aritméticos
Uso de símbolos matemáticos para cálculos:
- `+`, `-`, `*`, `/` (Adição, Subtração, Multiplicação, Divisão)
- `**` (Potência)
- `//` (Divisão Inteira)
- `%` (Resto da Divisão/Módulo)

### 3. Utilizando Módulos
Importação de bibliotecas externas e internas para expandir as funcionalidades do Python:
- Exemplo: `import math` ou `from math import sqrt`.

### 4. Manipulando Texto
Técnicas para trabalhar com strings:
- **Fatiamento**: `frase[9:13]`
- **Análise**: `len()`, `count()` e `find()`
- **Transformação**: `replace()`, `upper()`, `lower()`, `capitalize()`, `title()` e `strip()`
- **Divisão**: `Split()` e `join()`

### 5. Condições (Parte 1)
Estruturas de controle para tomada de decisão simples e composta:
- `if`: Se a condição for verdadeira.
- `else`: Se a condição for falsa.

- Padrão: `\033[style;text;backm`
